## VEYRA v0.1.0: Foundation (pre-release)

**Intelligent Living. Unified Operations.** VEYRA is a multi-tenant property and community
operations platform for condominiums, residential communities and property management
organisations.

This first pre-release contains the complete product and architecture documentation and the
monorepo foundation the product will be built on.

> ⚠️ **Not production software and not yet verified.** Dependencies have not been installed and
> no build or test run has been performed yet. Treat this as a design and scaffolding baseline.

### What's included

**Apps**

| App | What it is |
| --- | --- |
| `apps/api` | NestJS REST API (`/api/v1`): validated config, helmet, CORS allow-list, request IDs, standard error envelope, Zod validation, health checks, OpenAPI |
| `apps/worker` | BullMQ background worker that refuses tenant jobs without tenant context |
| `apps/console-web` | VEYRA Console (Next.js) shell |
| `apps/resident-mobile` | VEYRA Resident (React Native + Expo) shell with an API status check |
| `apps/marketing-web` | Public website home page |
| `apps/admin-web` | Internal platform admin shell |

**Shared packages:** `domain` (bigint `Money`, tenant context, job envelope),
`db` (tenant transaction helper for PostgreSQL row-level security), `api-contracts`,
`design-tokens`, `emails`, `web-config`.

**Documentation:** product vision, PRD, roadmap, personas, journeys, platform surfaces,
architecture, data model, multi-tenancy, API design, security and privacy baseline, threat
model, access control matrix, engineering standards and ADRs 0001-0004.

**Tooling:** Bun workspaces, Turborepo, strict TypeScript, Biome, Vitest, Docker Compose
(PostgreSQL 17, Redis 7), GitHub Actions CI with isolated database services.

### Known gaps

- `packages/db` Prisma schema and database client are not written yet.
- No `bun.lock` yet, so CI fails until dependencies are bootstrapped
  (`scripts/install-dependencies.ps1`).
- No sign-in, tenancy data model or business features yet. Those start in Phase 2.

### Next: Phase 2, Identity and multi-tenancy

Identity provider integration, organisations, memberships and roles, PostgreSQL row-level
